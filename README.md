
# ReadBrew


This repository is part of the front-end of the ReadBrew website system. - [@ReadBrew (Back-end)](https://github.com/matiasmov/ReadBrew)

The interface is based on the concept of welcoming themes, maintaining the aim of being a user-friendly site for readers.

Currently, the site has the following pages:

- Login
- Homepage
- cafeteria (incomplete)
- Library
## Tech Stack

**Style**: TailwindCSS

**Development**: Vue 3.0, Vite

## Run Locally

Clone the project

```bash
  git clone https://github.com/matiasmov/ReadBrew-frontend.git
```

Go to the project directory

```bash
  cd readbrew-frontend
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```
